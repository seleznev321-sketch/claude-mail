Политика конфиденциальности Claude Mail

Дата: 13.10.2026

Какие данные используются

Приложение получает доступ к Gmail владельца (письма, вложения, черновики, ярлыки) только после его согласия в окне входа Google.

Как используются

Данные обрабатываются на компьютере владельца по его команде: поиск и чтение писем, сохранение вложений, подготовка черновиков, ярлыки. Письма не отправляются и не удаляются автоматически.

Передача третьим лицам

Данные не продаются и не передаются третьим лицам для рекламы или иных целей. Использование данных, полученных из API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Хранение и удаление

Ключ доступа хранится только на компьютере владельца. Отозвать доступ можно в любой момент: myaccount.google.com/permissions.
